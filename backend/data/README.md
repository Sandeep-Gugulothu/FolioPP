# Dataset Documentation

This directory contains the stock market and sentiment data used for the FolioPP project.

## Files

- `SBIN.csv`: Historical stock data for State Bank of India (SBIN).
- `Data.csv`: Daily top news headlines and sentiment labels.
- `merged_stock_data.csv`: A combined dataset where news headlines are matched with stock price data by date (inner join).

## Data Sources

The datasets used in this project are sourced from Kaggle:

1.  **India Stock Data (NSE 1990-2020)**
    *   Source: [Kaggle - stoicstatic/india-stock-data-nse-1990-2020](https://www.kaggle.com/datasets/stoicstatic/india-stock-data-nse-1990-2020)
    *   Description: historical OHLCV data for various Indian stocks listed on the NSE.

2.  **News Headlines Dataset for Stock Sentiment Analysis**
    *   Source: [Kaggle - siddharthtyagi/news-headlines-dataset-for-stock-sentiment-analyze](https://www.kaggle.com/datasets/siddharthtyagi/news-headlines-dataset-for-stock-sentiment-analyze/data)
    *   Description: A collection of daily news headlines specifically curated for analyzing their impact on stock market movements.

## Preprocessing

The `merged_stock_data.csv` was generated by matching dates between the news headlines and the stock price data. Any dates that did not have both headlines and stock prices were removed to ensure a consistent dataset for training sentiment-based price prediction models.
